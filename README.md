## Соответствование требованиям и другие особенности:

1. Написано на чистом JavaScript без использования библиотек или фреймворков
2. Лоадер реализован в виде класса с публичным API, вынесен в отдельную папку и может быть переиспользован в других проектах
3. Реализованные состояния:
   1. Normal - базовое состояние, в котором путём задания Value можно управлять размером дуги. Начало дуги соответствует 12 часам, конец дуги при увеличении параметра Value движется по направлению часовой стрелки и достигает начала при значении 100
   2. Animated - независимое состояние, при котором блок начинает вращаться с некоторым периодом по часовой стрелке
   3. Hidden - состояние скрывающее блок со страницы
   4. \*Simulation - демонстрация возможностей модуля при которой симулируется процесс загрузка - заполнение и анимация индикатора загрузки
4. Результат выполнения задачи представлен в виде небольшого приложения с элементами управления
5. \*Поддержка смены ориентации экрана через CSS Media
6. \*Использование векторной графики, что полезно для UX
7. \*Ход выполнения был отснят с экрана с комментариями по ключевым моментам приложения

“\*“ - бонусный функционал

## Инструкция по использованию (API)

Для интеграции блока в проект достаточно: 

1. Выбрать элемент, в который будет вставлен модуль 
2. Передать его в конструктор с указанием параметра размера контейнера (при необходимости)
3. Используя методы объекта указать требуемые параметры для лоадера:
   1. setPercent(percent: number) - передается число - процентное заполнение шкалы
   2. setAnimation(isAnimation: boolean) - передается булевое значение, отвечающее за включение/отключение анимации
   3. setHidden(isHidden: boolean) - передается булевое значение, отвечающее за отображение/прятание контейнера

```javascript
import ProgressBlock from "../progress-module/ProgressBlock.js"

const progressNode = document.getElementById('place-for-progress-bar')
const progress = new ProgressBlock(progressNode, { size: 140 })

progress.setPercent(45);
progress.setAnimation(true); 
progress.setHidden(false); 
```

### Дополнительный функционал

В демонстрационном приложении реализована симуляция загрузки:

1. Нажмите Space для запуска плавного заполнения шкалы с анимацией до 100%
2. Симуляция автоматически синхронизирует состояние контроллеров

## Структура проекта

1. src - практика для отделения рабочих файлов от конфигурационных
2. src/progress-module - автономный модуль прогресс-бара
   1. ProgressBlock.js - инкапсулированная логика, отвечающая за рендеринг SVG, математику пересчета заполнения дуги и управление состоянием
   2. ProgressBlockStyles.css - стили для прогресс-бараи анимация
3. src/app - конкретное приложение, которое использует компонент
   1. app.js - логика демо-страницы
   2. app.scc - стили демо-страницы

### Как запустить локально

Так как проект использует нативные ES-модули для корректной работы путей, рекомендуется запускать через локальный сервер (я был вынужден использовать Live Server в VS Code).
